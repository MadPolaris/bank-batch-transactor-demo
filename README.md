# bank-batch-transactor-demo

A demo for monarch-core: financial batch transaction processing scenario (BankChain — sub-batch pipelines, re-batch routing, result classification, reconfirm handling).

Built on [`monarch-core`](https://github.com/MadPolaris/monarch-core) (resumable stage-queue engine) + [`common-core`](https://github.com/MadPolaris/common-core).

Extracted from [MadPolaris/playAkkaCQRS](https://github.com/MadPolaris/playAkkaCQRS) (`dag-engine-core/` module).

Run: `sbt test`
